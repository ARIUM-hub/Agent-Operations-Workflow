# 导出筛选条件提示设计

## 背景

客户使用问题归因智能体已经支持海外电商客服会话分析、批量上传、人工复核、最近记录筛选、平台筛选、筛选导出 CSV、运营概览时间范围筛选、平台概览下钻和记录详情复制。当前 `导出筛选 CSV` 会把最近记录筛选栏中的平台、关键词、问题类型、责任方、复核状态，以及运营概览中的时间范围一起带到后端导出接口。

但页面上还没有明确提示“这次筛选导出会应用哪些条件”。运营人员在切换多个条件后，可能误以为导出的是全部记录，或忘记当前还带着某个平台、时间范围或复核状态。本轮目标是新增一个只读提示，让导出前的条件更透明。

## 目标

- 在 `导出筛选 CSV` 附近新增只读提示区 `#export-filter-summary`。
- 无筛选条件且时间范围为全部时显示 `将导出全部记录`。
- 有筛选条件时显示 `筛选导出将应用：...`。
- 提示内容覆盖平台、关键词、问题类型、责任方、复核状态和时间范围。
- 平台和关键词显示用户输入原文。
- 问题类型、责任方、复核状态复用现有 `labelFor()` 中文映射。
- 时间范围显示 `全部记录`、`最近 7 天` 或 `最近 30 天`。
- 筛选输入、筛选重置、时间范围切换和页面初始化时都更新提示。
- README 补充说明导出前会显示当前筛选条件。

## 非目标

- 不修改 `/api/records/export.csv` 接口。
- 不改变 CSV 字段、编码或文件名。
- 不改变筛选导出 URL 的构建语义。
- 不新增后端接口。
- 不修改 JSONL 存储结构。
- 不改变最近记录本地筛选结果。
- 不调用模型，不增加供应商请求。

## 推荐方案

在现有 `#record-filter` 表单中，在 `导出筛选 CSV` 和 `清空` 按钮附近增加：

```html
<p id="export-filter-summary" class="export-filter-summary" aria-live="polite">将导出全部记录</p>
```

前端新增 `updateExportFilterSummary()`，读取：

- `#platform-filter`
- `#record-search`
- `#issue-filter`
- `#responsibility-filter`
- `#feedback-filter`
- `#summary-range`

函数把非空条件转为文案列表。时间范围只有不是 `all` 时才作为筛选条件展示；如果没有任何条件，显示 `将导出全部记录`。

示例：

```text
筛选导出将应用：平台：Amazon；关键词：battery；时间：最近 7 天；责任方：产品
```

更新触发点：

- `bindRecordFilters()` 内表单 `input` / `change` 事件。
- `resetRecordFilters(form)` 执行后。
- `bindSummaryRange()` 的 `change` 事件。
- DOMContentLoaded 初始化后。

这样提示文案始终贴近现有导出 URL 逻辑，但不改变任何导出行为。

## 备选方案

方案 A：点击 `导出筛选 CSV` 前弹确认框。能避免误导出，但会增加额外交互阻力，且每次导出都打断用户，因此不采用。

方案 B：在按钮文字中动态追加筛选数量，例如 `导出筛选 CSV（3 个条件）`。信息量太少，无法说明具体条件，仍可能误导出，因此不采用。

方案 C：由后端返回导出前预览。可以更精确地显示导出记录数，但需要新增接口和服务端计算。本轮只做轻量前端提示，因此不采用。

## 数据流

1. 页面渲染最近记录筛选栏和导出筛选按钮。
2. 页面初始化时 `updateExportFilterSummary()` 读取当前控件值。
3. 用户修改平台、关键词、问题类型、责任方或复核状态。
4. 前端更新本地记录筛选，并同步更新导出条件提示。
5. 用户切换运营概览时间范围。
6. 前端重新加载概览，并同步更新导出条件提示。
7. 用户点击 `导出筛选 CSV`。
8. 现有 `buildFilteredExportUrl()` 继续构建 URL，提示仅帮助用户理解即将导出的条件。

## 错误处理

- 提示区域不存在：更新函数直接返回，不影响筛选和导出。
- 某个筛选控件不存在：该条件忽略，不抛错。
- 下拉框值没有对应中文映射：回退显示原始值。
- 用户输入空白平台或关键词：按无条件处理。
- 时间范围值异常：显示为 `全部记录`，并保持现有导出 URL 逻辑。

## 验收标准

- 页面显示导出筛选条件提示区。
- 无筛选条件时提示 `将导出全部记录`。
- 有筛选条件时提示具体条件。
- 平台、关键词、问题类型、责任方、复核状态和时间范围都能反映到提示中。
- 清空筛选后提示恢复为 `将导出全部记录`，除非时间范围仍不是全部。
- 切换时间范围后提示同步更新。
- 导出 URL 和后端 CSV 行为保持不变。
- README 说明导出前会展示当前筛选条件。
- 全量测试通过。
